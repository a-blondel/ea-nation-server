Tiger Woods PGA Tour 2004 room names, TagField encoding, lobby roster behavior,
early Messenger dialect, packed statistics, leaderboards, news, and daily
tournament formats (calendar, settings and icons, scorecards, payouts and
earnings) are adapted from https://github.com/jeddyhhh/TW04OnlineServer
Commit: 8d4bc711e5858bce2a1759591e8303fd01df4201
Reference files: lobbyd.py, tagfield.py, twstats.py, twdb.py, twtourney.py,
docs/PROTOCOL.md.
Matches, results and Messenger lists are stored in this server's own tables, and
the tournament calendar is drawn by deterministic Java code instead of Python's
random generator. The companion Python website is not included.
